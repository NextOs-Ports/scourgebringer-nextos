# ScourgeBringer `v1.0.0-test.8` — community test

## English

This pre-release fixes the initial-menu selection bug without taking any
controller input away from gameplay.

The Android title logic retained a Discord entry that this build does not draw.
Pressing left or right could select it and leave every visible option
unhighlighted. An earlier experiment filtered horizontal title input, but the
title manager keeps stale `MainMenu` state during gameplay and that experiment
also removed lateral movement. It was discarded.

The final adapter leaves every axis and button untouched. After the game's own
update, it repairs only the hidden Discord selection by restoring the last
visible menu item. The exact release binary was physically checked for:

- left/right, up/down and visible highlighting in the root menu;
- horizontal input inside Settings;
- full-range left/right movement during gameplay;
- native controller, FMOD/ALSA audio and READY 9/9 startup.

The ZIP is BYO-data and contains no APK, extracted Android library, game asset,
save or log. Follow `scourgebringer/INSTALLATION.md` inside the archive and use
your own legally obtained compatible Android APK.

Known limit: the Mali-450 baseline and this regression are physically proven,
but the old-glibc bridge still awaits physical acceptance on an actual glibc
2.30 device. This is therefore a test release, not a new universal-support
claim.

## Português

Esta pré-release corrige a seleção do menu inicial sem retirar nenhuma entrada
do controle durante o gameplay.

A lógica Android mantinha uma entrada Discord que esta build não desenha.
Apertar esquerda ou direita podia selecioná-la e deixar todas as opções visíveis
sem destaque. Uma tentativa anterior filtrou o eixo horizontal no título, mas o
gerenciador conserva um estado `MainMenu` obsoleto durante a partida e aquela
tentativa também removeu o movimento lateral. Ela foi descartada.

A correção final preserva todos os botões e eixos. Depois do update nativo do
jogo, o adapter repara somente a seleção Discord invisível, restaurando a última
opção visível. O binário exato da release foi conferido fisicamente no menu,
em Configurações e com movimento completo para os dois lados no gameplay.

O ZIP é BYO-data: não inclui APK, bibliotecas Android extraídas, assets, saves ou
logs. Siga o `scourgebringer/INSTALLATION.md` existente dentro do arquivo e use
seu próprio APK Android compatível, obtido legalmente.

Limite conhecido: o baseline Mali-450 e esta regressão têm prova física, mas o
bridge de glibc antiga ainda precisa de aceitação num aparelho realmente baseado
em glibc 2.30. Por isso esta é uma versão de teste, não uma nova declaração de
suporte universal.
